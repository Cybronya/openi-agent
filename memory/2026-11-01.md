## CDP 守护进程 + HTML 直读（00:05 - 00:20）

承接 10-31 的 autoConnect 打通工作，本轮解决用户反馈的两个体验问题。

### 用户反馈
1. 「每次申请控制的时候，都是要我点确定，有时候你说链接失败，我这边都没来的及点确定，
   然后好多个确定存在，我一起点的，可能是这个原因，导致你超时」
2. 「能不能不通过截图，你能直接读取页面上的 html」

### 问题 1 根因与解法：常驻守护进程

**根因**：Chrome 的 autoConnect 端点**每建立一个新连接都要弹窗请求授权**。
独立脚本 `cdp_autoconnect.py` 每次运行都新建连接 → 每次都弹窗。
用户「一起点多个确定」让多个授权请求并发，且上一个连接未释放时新连接直接挂起超时。

**解法**：`tools/cdp_daemon.py` —— 守护进程与 Chrome 只建立**一次**连接并长期保持，
后续操作通过本地 TCP 端口（默认 8765）发 JSON 命令，**不产生新的 Chrome 连接**。

实测：连续 5 条命令全部成功，**零弹窗**。

实现要点：
- 服务端用 `asyncio.start_server` 监听 127.0.0.1:8765
- 客户端 `--client` 模式通过 socket 发一行 JSON、读一行 JSON
- 守护进程内用 `asyncio.Lock` 串行化命令，避免并发互相干扰
- 命令：pages / read / html / eval / shot / ping

### 问题 2 解法：HTML 直读

新增 `html` 命令，四种模式：
| mode | 内容 | 实测体积 |
|------|------|---------|
| outer | `document.documentElement.outerHTML` | 1,801,498 字符 |
| body | `document.body.innerHTML` | 1,782,516 字符 |
| head | `document.head.innerHTML` | — |
| sel | CSS 选择器命中的 outerHTML | table thead 1,344 字符 |

独立脚本 `cdp_autoconnect.py` 也同步加入了 `html` 子命令。

**比截图的优势**：能拿到 `class`、`is-hidden`、`el-table-column--selection`、
`aria-hidden` 等截图里不可见的属性；可用选择器精准取片段（1.9 KB vs 1.8 MB，
体积小三个数量级）；无视觉歧义。

`read` 命令同时增强了结构化输出，新增**表格抽取**（表头 + 行数据）。
实测 cloudbrains 页 5 张表格全部抽出，表头为
`['', '', '任务类型', '状态', '算力资源信息', '创建时间', '运行时长', '项目', '', '']`。

### 关键排障：JS 表达式里的引号
`{"cmd":"eval","expr":"...'.jp-Notebook'..."}` —— **JS 内部一律用单引号**。

现象是表达式返回 null 或直接报错。批量测多条命令时用
`python tools/cdp_daemon.py --client "{\"cmd\":\"eval\",\"expr\":\"$e\"}"` 的双引号包裹形式，
内部 JS 用单引号。
